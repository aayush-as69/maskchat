# MaskChat Moderation

## Message filtering

Messages are checked before delivery for contact details, links, attachments and abusive language. The filter also attempts to recognize common evasion patterns.

## Reports

A participant can report a session and optionally attach visible messages as evidence. Moderators can review reports, assign them and resolve them.

## Offenders

Moderation state is associated with an opaque internal offender reference rather than exposing a user's real identity to participants. Temporary and permanent bans are supported.

## Limitations

Content filtering is heuristic. It should be supplemented with moderator review, rate limiting, abuse escalation and clear pilot policies.
